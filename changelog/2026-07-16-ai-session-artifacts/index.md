title: Markdown artifacts in AI sessions
tags: ['AI Chat', 'Windmill AI']
description: In AI sessions, the assistant can now save longer structured output like plans, specs and design write-ups as markdown artifacts that persist for the whole session. Artifacts open in the session preview panel with Copy, Download as .md and a Preview / View source toggle, and are listed in the new status line above the chat input that gathers the session's drafts, artifacts and jobs. They are stored locally in your browser, restored when you reopen the session and removed when the session is deleted.
